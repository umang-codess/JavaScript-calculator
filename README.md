# Simple JavaScript Calculator

A clean, responsive, and fully functional web calculator built using basic **HTML5, CSS3, and JavaScript**.

---

## ✨ Features
- **Basic Arithmetic:** Performs addition, subtraction, multiplication, and division.
- **Clear:** Includes `C` (Clear) and backspace capabilities for easy corrections.
---

## 🛠️ Technologies Used
- **HTML5:** Structures the calculator layout and button elements.
- **CSS3:** Handles modern styling and button effects
- **JavaScript (Vanilla):** Powers the calculation logic and user input events.

---

## 💻 How to Run Locally

1. **Clone or download** this repository to your local machine.
2. Double-click the **`index.html`** file to open and run the project instantly in any web browser.
